## Selected Pattern

**Pattern 4: Split Pane Detail - k9s Style**

The detail panel is vertically split into two sections:

1. **Upper**: Plugin metadata (existing)
2. **Lower**: Component list (new)

Components are always visible without additional interaction, providing high information density.

```
┌────────────────────────────┬────────────────────────────────────┐
│  ▸ plugin-a                │  📦 my-awesome-plugin              │
│    plugin-b                │  ─────────────────────────────     │
│  ▸ my-awesome-plugin ◀     │  Author: Laststance                │
│    plugin-c                │  Version: 1.2.0                    │
│                            │  License: MIT                      │
│                            ├────────────────────────────────────┤
│                            │  ── Components ──────────────────  │
│                            │  Skills (7)                        │
```

**Design decisions**:

- Max 3 items per category, then "+N more..."
- No scroll needed within component section
- Navigation: Arrow keys + Emacs bindings (Ctrl+n/p/f/b) - unified app-wide

### Step 3: Collapsed List with "+N more" Display

**File**: `source/components/ComponentList.tsx`
**Estimate**: ~1 hour

**Features**:

- Show first 3 items per category
- Display "+N more..." for categories with >3 items
- No scroll needed, no additional keyboard navigation
- Consistent with existing navigation (Arrow keys + Emacs bindings)

```typescript
const MAX_VISIBLE_ITEMS = 3

/**
 * Props for CategorySection
 */
interface CategorySectionProps {
  /** Category display name (e.g., "Skills", "Agents") */
  name: string
  /** Component items to display */
  items: ComponentInfo[]
}

/**
 * Single category section with collapsible items
 * Shows first N items, then "+M more..." for overflow
 * @returns React node for the category section
 */
function CategorySection({
  name,
  items,
}: CategorySectionProps): React.ReactNode {
  const visibleItems = items.slice(0, MAX_VISIBLE_ITEMS)
  const remainingCount = items.length - MAX_VISIBLE_ITEMS

  return (
    <Box flexDirection="column">
      <Text color="yellow">{name} ({items.length})</Text>
      {visibleItems.map((item) => (
        <Text key={item.name}> • {item.name}</Text>
      ))}
      {remainingCount > 0 && (
        <Text dimColor> └─ +{remainingCount} more...</Text>
      )}
    </Box>
  )
}
```

**Keyboard bindings** (app-wide, already unified):

- `↑` / `Ctrl+p`: Move up
- `↓` / `Ctrl+n`: Move down
- `←` / `Ctrl+b`: Move left / back
- `→` / `Ctrl+f`: Move right / forward
